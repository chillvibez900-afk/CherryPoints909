# CherryPoints MVP

A mobile-friendly prototype for a travel rewards platform.

## Included
- CherryPoints balance
- Point packages including **20,000 points for $50**
- Free welcome and daily points
- Referral concept
- Hotel and flight demo deals
- Redemption flow
- Local demo balance using browser localStorage

## Run it
Open `index.html` in a browser.

## Production roadmap
1. Add real authentication.
2. Move balances to a server-side database with an immutable points ledger.
3. Integrate Stripe or another approved payment processor.
4. Connect an authorized hotel/flight inventory provider.
5. Build booking, cancellation, refund and customer-support workflows.
6. Add fraud controls, rate limits and audit logs.
7. Define point expiration, refunds and promotional rules.
8. Have counsel review the loyalty program, travel seller/agency requirements, supplier contracts, taxes, consumer disclosures and any restrictions on selling or transferring third-party airline/hotel points.

This prototype deliberately does not process real money or make real travel reservations.
